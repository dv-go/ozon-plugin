# ozon-plugin

Небольшой пример клиента для работы с Ozon Seller API на Python.

## Быстрый старт

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Укажите ключи авторизации в переменных окружения:
   ```bash
   export OZON_CLIENT_ID=your_client_id
   export OZON_API_KEY=your_api_key
   ```

3. Запустите пример:
   ```bash
   python main.py
   ```

4. Чтобы получить информацию о складах по артикулу товара:
   ```bash
   python stocks.py YOUR_ARTICLE
   ```
